Title e meta description são os primeiros elementos que o usuário vê no
resultado de busca — antes mesmo de clicar no seu site. Um title mal
dimensionado é cortado com "...", e uma description fraca reduz a taxa de
clique mesmo quando a página está bem-rankeada.

Esta ferramenta mostra, em tempo real, como o Google provavelmente vai
exibir seu title e description, além de contar os caracteres para você
ficar dentro do limite recomendado.
