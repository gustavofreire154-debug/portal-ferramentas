Juntar arquivos PDF em um único documento é uma necessidade comum: reunir
comprovantes para um processo, organizar um portfólio, montar um material
de apresentação a partir de páginas separadas, ou simplesmente evitar
enviar vários anexos separados por e-mail.

## Como funciona por trás dos panos

Diferente de muitas ferramentas online que enviam seu arquivo a um
servidor remoto para processar e depois devolvem o resultado, esta
ferramenta usa uma biblioteca que roda **inteiramente no seu navegador**.
Isso significa que o conteúdo dos seus PDFs nunca sai do seu computador —
uma vantagem tanto de velocidade quanto de privacidade, especialmente
importante para documentos com informação sensível (contratos, boletos,
comprovantes).

## Passo a passo

1. Selecione dois ou mais arquivos PDF.
2. Reordene usando as setas, se precisar de uma ordem específica.
3. Clique em "Juntar" e aguarde o processamento.
4. Baixe o arquivo final combinado.

## Quando usar

- Reunir comprovantes de pagamento em um único arquivo para prestação de
  contas.
- Combinar páginas escaneadas separadamente em um documento único.
- Montar um portfólio ou apresentação a partir de arquivos exportados de
  diferentes fontes.
